Módulo 2: Estruturas de Controle e Fluxo

Por padrão, o JavaScript lê o código de cima para baixo, linha por linha. As estruturas de controle permitem tomar decisões e repetir tarefas conforme a necessidade do programa.

1. Estruturas Condicionais (if, switch e Ternário)

  • if / else: executa um bloco de código apenas quando uma condição é verdadeira.
  • Operador Lógico E (&&): combina duas condições e só retorna true se ambas forem verdadeiras.
  • Operador Condicional Ternário: atalho em uma única linha no formato condicao ? valorSeVerdadeiro : valorSeFalso.
  • switch e default: ideal para comparar uma expressão com vários casos (case) exatos. Se nenhum caso bater, o bloco default é executado.
const idade = 20, temCarteira = true;
if (idade >= 18 && temCarteira) {
  console.log("Pode dirigir");
}

const status = idade >= 18 ? "Adulto" : "Menor";

switch (status) {
  case "Adulto": console.log("Acesso liberado"); break;
  default: console.log("Acesso restrito");
}

2. Laços de Repetição (for, while, do...while e for...of)

  • for: ideal quando você já sabe exatamente quantas vezes o bloco deve se repetir.
  • while: repete enquanto a condição for verdadeira, testando antes de cada execução.
  • do...while: executa o bloco pelo menos uma vez antes de verificar a condição.
  • for...of: percorre diretamente cada valor de um objeto iterável, como um Array, sem precisar controlar índices manualmente.

3. Controlando o Laço (break e continue)

Dentro de um loop, você pode alterar o fluxo a qualquer momento:

  • break: encerra imediatamente todo o laço de repetição (ou um bloco switch).
  • continue: pula apenas a iteração atual e avança direto para a próxima volta do loop.
const notas = [8, 5, 10];
for (const nota of notas) {
  if (nota === 5) continue; // Pula o 5 e segue o loop
  console.log("Nota:", nota);
}

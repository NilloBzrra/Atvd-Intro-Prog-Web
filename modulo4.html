Módulo 3: Manipulação de DOM

O DOM (Document Object Model) é a representação em árvore de todos os elementos HTML da página. Através do objeto global document, o JavaScript pode ler, modificar, criar e remover elementos em tempo real.

1. Selecionando Elementos na Página

  • document.getElementById("id"): busca um elemento pelo valor exato do seu atributo id.
  • document.querySelector("seletor"): retorna o primeiro elemento que corresponde a qualquer seletor CSS (como .classe, #id ou button).

2. Alterando Conteúdo e Classes CSS

  • textContent: altera apenas o texto puro de um elemento sem interpretar tags HTML, o que protege a aplicação contra ataques XSS.
  • classList.toggle("classe"): adiciona uma classe CSS se ela não existir no elemento, ou a remove caso já esteja aplicada.
const titulo = document.querySelector("h1");
titulo.textContent = "Novo Título Seguro";
titulo.classList.toggle("destaque");

3. Criando, Inserindo e Removendo Elementos

Você pode construir novos elementos HTML dinamicamente via código:

  • document.createElement("tag"): cria um novo elemento HTML em memória.
  • pai.appendChild(filho): insere o novo elemento dentro de um elemento pai já existente na página.
  • elemento.remove(): remove diretamente o elemento selecionado da árvore do DOM.
const item = document.createElement("li");
item.textContent = "Item adicionado via JS";
document.getElementById("lista").appendChild(item);
// Para excluir depois: item.remove();

4. Eventos e Formulários (addEventListener e preventDefault)

Para reagir às ações do usuário (cliques, teclas, envios), registramos ouvintes com addEventListener("evento", funcao). Em formulários, o método event.preventDefault() bloqueia o recarregamento padrão da página para que possamos validar ou processar os dados com JavaScript.

form.addEventListener("submit", (event) => {
  event.preventDefault(); // Evita recarregar a página
  console.log("Formulário enviado com sucesso!");
});

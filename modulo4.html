Módulo 4: Funções, Parâmetros e Escopo

Funções são blocos de código reutilizáveis que recebem valores (parâmetros), executam uma tarefa e devolvem um resultado com return. Variáveis criadas dentro da função ficam protegidas no escopo local.

function calcularDesconto(valor, percentual = 10) {
  const desconto = valor * (percentual / 100);
  return valor - desconto;
}

const somar = (a, b) => a + b;

Módulo 4: Funções, Parâmetros e Escopo

4.1 Anatomia de uma Função: Parâmetros, Argumentos e Retorno

Funções são blocos de código nomeados e reutilizáveis que recebem entradas, processam uma lógica e devolvem um resultado. Distinguimos dois conceitos essenciais na comunicação com funções:

  • Parâmetros: São as variáveis locais declaradas entre parênteses na definição da função. Podem receber valores padrão (default parameters) caso nenhum valor seja informado.
  • Argumentos: São os valores reais enviados na hora em que invocamos a função.
  • Instrução return: Encerra imediatamente a execução da função e devolve o resultado para quem a chamou. Sem return, a função retorna undefined.
function calcularDesconto(valor, percentual = 10) {
    const desconto = valor * (percentual / 100);
    return valor - desconto;
}

const precoFinal = calcularDesconto(200, 15); // 200 e 15 são argumentos → 170
const precoPadrao = calcularDesconto(200); // Usa percentual = 10 → 180

4.2 Function Expressions e Arrow Functions (=>)

Além da declaração tradicional, podemos armazenar funções anônimas em constantes (Function Expressions) ou utilizar a sintaxe moderna de Arrow Functions (=>). Quando o corpo da Arrow Function possui apenas uma expressão e não utiliza chaves {}, o retorno ocorre de forma implícita.

// Arrow Function com bloco explícito
const saudar = (nome) => {
    return `Bem-vindo(a), ${nome}!`;
};

// Arrow Function concisa com retorno implícito
const somar = (a, b) => a + b;
const quadrado = n => n * n;

4.3 Escopo Léxico: Global, de Função e de Bloco

O escopo determina onde uma variável é visível e pode ser acessada no código. O JavaScript segue o modelo de escopo léxico (definido pela posição onde o código foi escrito):

NÍVEL DE ESCOPO ONDE É CRIADO VISIBILIDADE
Escopo Global Fora de qualquer função ou bloco Acessível em todo o arquivo.
Escopo de Função Dentro do corpo de uma função. Restrito ao interior da função.
Escopo de Bloco Dentro de if, for, while (com let e const). Restrito ao par de chaves {}.

4.4 Hoisting (Içamento)

Antes de executar o código linha por linha, o motor JavaScript registra as declarações na memória. Por isso, funções criadas com function nome() {} sofrem hoisting completo e podem ser chamadas antes mesmo da linha em que foram escritas. Já Arrow Functions armazenadas em const seguem as regras da constante e só podem ser invocadas após sua declaração.

iniciarSistema(); // Funciona devido ao hoisting de Function Declaration

function iniciarSistema() {
    const mensagemInterna = "Sistema online";
    console.log(mensagemInterna);
}
Dica do Professor — Separação de Responsabilidades

Evite colocar console.log() dentro de funções de cálculo. Prefira sempre devolver o resultado com return e exibir no console fora da função — assim você consegue reaproveitar esse valor em cálculos futuros ou na interface HTML.

Módulo 1: Variáveis e Fundamentos

JavaScript dá vida e interatividade às páginas web. Para dominar a linguagem, começamos aprendendo como guardar dados na memória, comparar valores e entender como os tipos funcionam por baixo dos panos.

1. Declarando Variáveis (const, let e var)

Variáveis são caixas etiquetadas na memória do computador:

  • const: cria uma constante cujo valor não pode ser reatribuído depois de definido. É a escolha padrão no dia a dia.
  • let: cria uma variável que permite trocar seu valor ao longo do programa. Se você declarar let x; sem valor inicial, ela recebe automaticamente undefined.
  • var: forma antiga de declarar variáveis, evitada em códigos modernos por problemas de escopo.
const linguagem = "JavaScript"; // Não pode ser reatribuída
let pontos = 0; // Pode mudar depois
let semValor; // Vale undefined por padrão

2. Tipos Primitivos, typeof null e Template Strings

Os dados básicos em JavaScript incluem textos (strings), números (numbers), lógicos (booleans), undefined e null (ausência intencional de valor). Uma curiosidade histórica da linguagem é que typeof null retorna "object" devido a um bug legado mantido por compatibilidade.

Para montar textos dinâmicos sem precisar somar várias strings, usamos Template Strings com crases (` `) e a sintaxe ${variavel} para interpolação.

const aluno = "Ana";
const saudacao = `Olá, ${aluno}! Bem-vinda.`;
console.log(typeof null); // Exibe: "object"

3. Operadores, Conversão de Tipos e Coerção

  • Igualdade Estrita (===) vs. Solta (==): o operador === compara valor e tipo sem converter nada automaticamente, evitando erros inesperados.
  • Resto da Divisão (%): retorna o que sobra de uma divisão inteira (ex: 10 % 3 resulta em 1).
  • Concatenação vs. Soma: ao usar + entre texto e número, como em "5" + 3, o JavaScript converte o número em texto e junta ambos, resultando em "53".
  • Conversão Explícita: a função parseInt("42px") lê o início do texto e extrai o número inteiro 42.

4. Valores Truthy, Falsy e Depuração

Em testes lógicos, valores como 0, "" (string vazia), null, undefined e NaN se comportam como falsos (falsy). Qualquer string não vazia — inclusive o texto "false" — é avaliada como verdadeira (truthy).

Para inspecionar variáveis e depurar o código durante o desenvolvimento, usamos console.log() no painel do desenvolvedor do navegador.

console.log(5 === "5"); // false (tipos diferentes)
console.log("5" + 3); // "53" (concatenação)
console.log(parseInt("42px")); // 42
console.log(Boolean("false")); // true (string não vazia é truthy)
